## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/adilafarhana-dev/afsal-najila-wedding-card.git
cd afsal-najila-wedding-card

# Start a local HTTP server
python -m http.server 8080
```

Open your browser at:
`http://localhost:8080/index.html`

## 🌐 Publish to GitHub Pages (Free Live URL)

To share this invitation online with family and friends:
1. Go to your repository on GitHub: **`https://github.com/adilafarhana-dev/afsal-najila-wedding-card`**
2. Click on **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your wedding invitation will be live at:
   **`https://adilafarhana-dev.github.io/afsal-najila-wedding-card/`**
